#### Corrección de `src/app/api/reports/route.ts` (error demostrado)
- **Síntoma:** "Informe Premium" no se podía preparar; `/api/reports` devolvía 500.
- **Causa:** la ruta hacía `profiles.select("is_admin,is_founder,plus_access_until")` y la columna `profiles.is_admin` **no existe** en la BD de producción (error PostgREST `42703`, comprobado con consulta de solo lectura).
- **Arreglo:** `.select("*")` — lee las columnas que existan; las que faltan quedan `undefined` sin error.
- **Modo compatible (ya presente antes del fix):** si la tabla `access_grants` no existe (`42P01`/`PGRST205`), todos los usuarios autenticados tienen acceso a informes. No se activa freemium, ni límite de 30 gastos, ni trial, ni bloqueo premium.
- **Verificado en local** con sesión real: ciclo 2026-10 → 200 con datos (gasto 333,36 €, ingresos 1813,00 €, disponible 134,58 €, 21 movimientos) y PDF descargado (`kakebo-informe-cycle-2026-10.pdf`, PDF válido).
- **Conocido, sin corregir:** sin sesión, `/api/reports` devuelve 500 en vez de 401 (el `catch` convierte el `ApiError` de `requireAuth` en 500).

## 4. Montar el entorno en otro ordenador

```bash
git clone https://github.com/mrsteppenwolf627/kakebo.git
cd kakebo
git checkout feat/app-visual-refresh
npm install
# Crear .env.local (NO está en git: .gitignore ignora .env*).
# Copiarlo de forma segura desde el otro ordenador o regenerarlo desde Vercel/Supabase.
npm run dev            # http://localhost:3000/app
```

Variables mínimas para que `/app` funcione: `NEXT_PUBLIC_SUPABASE_URL` y `NEXT_PUBLIC_SUPABASE_ANON_KEY`. Sin ellas `/app` da 500 ("Your project's URL and API key are required").

**Ojo:** `.env.local` apunta a la Supabase de **producción**. Lo que se cree o borre en local afecta a datos reales.

### Problemas conocidos en local (Windows)
- **"Runtime Error: Jest worker encountered 2 child process exceptions"**: compilación de desarrollo corrupta o procesos `next dev` huérfanos. Solución: parar el proceso del puerto 3000 (y sus hijos), borrar `.next/` y volver a `npm run dev`.
- **Servidor parado por falta de memoria**: Claude Code puede detener procesos en segundo plano si la RAM va justa; volver a arrancar `npm run dev`.
